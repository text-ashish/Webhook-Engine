4 Self-Initiated Improvements implemented beyond the core requirements
01 — Health Scoring
Every endpoint gets a live health status computed from its last 20 deliveries. Zero failures = healthy. Under 30% failure rate = degraded. Above 30% = failing.
src/api/endpoints.js
computeHealth()
getEndpointStats()
updates every 5s
02 — Circuit Breaker
After 5 consecutive failures the circuit opens — the worker stops hitting that endpoint for 60 seconds. Then moves to half-open for one test request. Success closes it. Failure reopens it.
src/utils/circuitBreaker.js
closed → open → half-open
persisted in DB
checked before every delivery
03 — Secret Rotation
Every endpoint has a Rotate Secret button. One click generates a fresh 32-byte HMAC secret, invalidates the old one immediately, and shows the new secret exactly once.
POST /api/endpoints/:id
/rotate-secret
crypto.randomBytes(32)
old secret invalidated instantly
04 — Rate Limiting
Three tiers applied only to write operations — GET requests never count against limits so dashboard auto-refresh never triggers them.
global: 2000 / 15min
trigger: 120 / min
create: 60 / min
src/middleware/rateLimiter.js
